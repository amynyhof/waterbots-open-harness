## What this settles, in plain words

**The design language of this shell prevailed.** The compatibility goal
had been waiting on a design session with the production side, and the
outcome is that almost nothing arrives inbound. Three things this
repository already does are now binding rather than merely current:
the Frost light theme, the left navigation rail with its "Collapse" row
and "<" glyph, and the chat dock's citation and formatting rules.

**Two things do change, and neither is built.**

1. **The brightness pull-up**, which the canon asks to be proposed as
   one sized step. It is logged as item S8 in
   [OPEN_ITEMS.md](./OPEN_ITEMS.md).
2. **The rail width rider** — widen the rail modestly whenever it is
   next opened for another reason. The canon is explicit that this is
   **not its own work item**, so it has none. It lives here, and item S8
   points at it so it is not lost.

## Where this document sits among the others

It is a rulebook, in the same posture as
[PROCESS_RULES_for_ShellB.md](./PROCESS_RULES_for_ShellB.md): brought by
the maintainer, binding, and published.

**It does not restate what BRAND.md and UI_REFERENCE.md already own.**
Those two hold the values themselves — the palette, the type, the
component shapes — and they are gitignored and never publish. This file
holds the ruling about which of them apply here and at what strength.
**Where this file and BRAND.md speak to the same point they agree.** If
they ever diverge, that is a defect to raise with the maintainer, not a
choice to make.

## One thing raised on receipt, and ruled the same day

**The canon names Phoebe's identity colour as "violet."** In BRAND.md,
violet is **Iris** `#7B5BE6`. Phoebe's colour in this repository is
**Anemone** `#A04E7E`, which BRAND.md describes as muted berry-magenta,
set by the maintainer's ruling of 22 Aug 2026 — a ruling made precisely
to move her off the provisional Plum and Iris pair taken from her
portrait.

**Nothing was changed on the strength of one word.** It was raised, and
the maintainer ruled on 27 Aug 2026: **"violet" was loose wording, and
the ruling of 22 Aug holds.** Phoebe stays Anemone. Bridget stays
provisional at her current colour.

**A rider was set at the same time.** After the brightness pull-up
lands, both agent identity colours are re-reviewed against the status
taxonomy — an agent colour must never read as a project status, and
Bridget's soft Surf sits near *Live*. It rides on item S8 in
[OPEN_ITEMS.md](./OPEN_ITEMS.md).
