# feasibility

**Version 0.1.0.** One tool: selection considerations for projects that have
already passed the eligibility gate. Guidance. Never a bar to entry.

**This folder does not hold the cards.** They live at the repository root:

- Cards: [`feasibility-cards-vwba.md`](../../../../feasibility-cards-vwba.md)
- Reader: [`src/lib/phoebeCards.ts`](../../../../src/lib/phoebeCards.ts)

Ten considerations. None skipped. They carry no ranking. Weighing them is the
visitor’s job. Approved by the maintainer, 21 Aug 2026.
