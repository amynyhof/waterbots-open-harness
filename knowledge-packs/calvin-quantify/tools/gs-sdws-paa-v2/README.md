# gs-sdws-paa-v2

**Version 0.1.0.** Live `methodPacks` key: `gs-sdws-paa-v2`.

Gold Standard safe-drinking-water carbon screening, Paris-aligned version.
Ex-ante. Screening tier. Consultant review.

Live arithmetic stays in [`src/lib/gsSdws.ts`](../../../../src/lib/gsSdws.ts).
This folder does not copy it.

A blank figure is never read as zero. This screening does not apply the further
v2.0 adjustments the methodology names; the tab on the live site says so. The
credited figure is lower, never higher.
