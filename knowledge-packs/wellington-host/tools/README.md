# wellington-host tools

**None yet.** Wellington hosts and routes. He has no named tool on this site, and
no Tool tab on his screen.

This folder is here so the standing pack shape is visible. An empty `tools/` with
a note is allowed only while the seat truly has no tools.

When a tool is named, it gets:

```
tools/<tool-id>/
  README.md
  CHANGELOG.md
```

and `wellington-host/CHANGELOG.md` cites `tool-id@version`.
