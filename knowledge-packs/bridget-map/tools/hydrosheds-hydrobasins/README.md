# hydrosheds-hydrobasins

**Version 0.1.0.** One tool: worldwide watershed basin boundaries, HydroBASINS
Level 4 at world view, Level 6 from zoom 5.

Live geometry: `public/hydrobasins_lev04.json`, `public/hydrobasins_lev06.json`.
Attribution strings: [`src/lib/licences.ts`](../../../../src/lib/licences.ts).
This folder does not copy the data.
